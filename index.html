The lab

Built, shipped and run at home

Everything here runs on hardware I own and operate, so every project goes all the way from the first commit to production.

  • Self-hosted server

    A home server runs the apps, databases and monitoring behind every project.

  • Containers everywhere

    Each service ships as a Docker image behind a reverse proxy with automatic TLS.

  • Cloudflare at the edge

    Traffic reaches the lab through Cloudflare for caching, DNS and protection.

  • CI/CD to production

    Every merge builds versioned images and deploys them to the lab automatically.
